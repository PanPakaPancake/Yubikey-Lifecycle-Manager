# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: we want this to be a friendly, harassment-free place for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

- Be respectful and constructive, also when you disagree.
- Assume good intent, and help newcomers.
- Focus on what is best for the project and its users.
- No harassment, insults, personal or political attacks, sexualized language or imagery, and no publishing of others' private information.

This applies in all project spaces (issues, pull requests, discussions, reviews) and when someone represents the project elsewhere.

## Reporting

If someone violates this code of conduct, please tell the maintainer, [@PanPakaPancake](https://github.com/PanPakaPancake), privately via the contact options on their GitHub profile. Reports are handled confidentially. The maintainer may remove, edit or reject contributions and may temporarily or permanently ban contributors whose behavior is harmful, following the enforcement guidelines of the Contributor Covenant.
